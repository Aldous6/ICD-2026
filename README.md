# Introducción a la Ciencia de Datos (ICD 2026)

Este repositorio reúne materiales de la asignatura y los organiza según su propósito. La idea es mantener separados los recursos de consulta, las prácticas y el proyecto.

[Lecturas/](Lecturas/) está reservado para los textos de clase. [Notebooks/](Notebooks/) contiene cuadernos de consulta; actualmente hay dos extractos del *Python Data Science Handbook*. En [Practicas/](Practicas/README.md) están los trabajos prácticos y sus instrucciones de ejecución. [Proyecto/](Proyecto/) está reservado para el trabajo del proyecto.

Si buscas una entrega práctica, empieza por el [README de Prácticas](Practicas/README.md), donde se describen los conjuntos de datos, los requisitos y los pasos de ejecución. Las carpetas de Lecturas y Proyecto aún no tienen contenido.
