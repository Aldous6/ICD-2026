# Introducción a la Ciencia de Datos (ICD 2026)

Este repositorio reúne materiales de la asignatura y los organiza según su propósito. La idea es mantener separados los recursos de consulta, las prácticas, las tareas y el proyecto.

[Lecturas/](Lecturas/) está reservado para los textos de clase. [Notebooks/](Notebooks/) contiene cuadernos de consulta; actualmente hay dos extractos del *Python Data Science Handbook*. En [Practicas/](Practicas/README.md) están las prácticas y sus instrucciones de ejecución. En [Tareas/](Tareas/README.md) están las tareas. [Proyecto/](Proyecto/) está reservado para el trabajo del proyecto.

Si buscas una entrega, consulta el [README de Prácticas](Practicas/README.md) o el [README de Tareas](Tareas/README.md). Las carpetas de Lecturas y Proyecto aún no tienen contenido.
