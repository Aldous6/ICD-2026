# Introducción a la Ciencia de Datos (ICD 2026)

Este repositorio reúne materiales de la asignatura y los organiza según su propósito. La idea es mantener separados los recursos de consulta, las prácticas, las tareas y el proyecto.

[Lecturas/](Lecturas/) está reservado para los textos de clase. En [Notebooks/](Notebooks/README.md) están los cinco bloques de revisión del *Python Data Science Handbook*: IPython, NumPy, pandas, Matplotlib y aprendizaje automático, con explicaciones, ejercicios resueltos y resultados guardados. En [Practicas/](Practicas/README.md) están las prácticas y sus instrucciones de ejecución. En [Tareas/](Tareas/README.md) están las tareas. [Proyecto/](Proyecto/) está reservado para el trabajo del proyecto.

Si buscas una entrega, consulta el [README de Prácticas](Practicas/README.md) o el [README de Tareas](Tareas/README.md). Las carpetas de Lecturas y Proyecto aún no tienen contenido.
